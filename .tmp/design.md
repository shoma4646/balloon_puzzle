# Balloon Puzzle - 要件定義書

## プロジェクト概要

スイカゲームの逆転発想で、タップで風船を離すと浮力で上昇し、同じ種類の風船同士がぶつかるとマージして大きくなるパズルゲーム。最大サイズの風船同士が接触すると消滅してポイントを獲得する。

## ゲームコンセプト

- **コアメカニクス**: タップで風船を離し、浮力で上昇させる
- **マージシステム**: 同じ種類の風船がぶつかると1段階大きな風船になる
- **スコアリング**: 風船を離すだけでポイント獲得、最大サイズの風船が消えると高得点
- **ゲームオーバー**: 画面上部から風船が溢れる

## ゲーム仕様

### 風船の種類
8段階の風船を用意（小→大）

| レベル | 色 | サイズ(相対) | 説明 |
|--------|-----|-------------|------|
| 1 | 赤 | 1.0 | 最小 |
| 2 | オレンジ | 1.3 | |
| 3 | 黄色 | 1.6 | |
| 4 | 黄緑 | 1.9 | |
| 5 | 緑 | 2.2 | |
| 6 | 水色 | 2.5 | |
| 7 | 青 | 2.8 | |
| 8 | 紫 | 3.1 | 最大（消滅可能） |

### 物理演算

#### 浮力
- 風船は常に上方向に力を受ける
- 浮力 = 風船のサイズに比例
- 重力は負の値として設定（上向きの力が勝る）

#### 横方向の慣性
- タップ時の初速度は横方向にランダムな微小速度を付与
- 空気抵抗をシミュレート（速度に比例した減衰）
- 他の風船や枝との衝突で横方向の運動量を保持

#### 衝突判定
- 風船同士: 円形の衝突判定
- 風船と枝: 矩形と円の衝突判定
- 同種の風船が接触→マージ処理
- 最大サイズ(Lv.8)同士が接触→消滅処理

### ステージ構成

5つのステージを用意（難易度別）

#### Stage 1: チュートリアル
- 枝の数: 1本（画面中央上部）
- 枝の長さ: 短め
- 難易度: 易

#### Stage 2: 基本
- 枝の数: 2本（左右に配置）
- 枝の長さ: 中
- 難易度: 易〜中

#### Stage 3: 中級
- 枝の数: 3本（左・中央・右）
- 枝の長さ: 中〜長
- 難易度: 中

#### Stage 4: 上級
- 枝の数: 4本（不規則配置）
- 枝の長さ: 様々
- 難易度: 中〜難

#### Stage 5: エキスパート
- 枝の数: 5本（複雑な配置）
- 枝の長さ: 様々
- 難易度: 難

### スコアリングシステム

#### 基本ポイント
- 風船を離す: 10ポイント × 風船レベル
  - Lv.1風船を離す: 10pt
  - Lv.2風船を離す: 20pt
  - ...
  - Lv.8風船を離す: 80pt

#### マージボーナス
- 2つの風船がマージ: 50ポイント × 新しい風船レベル
  - Lv.1→Lv.2: 100pt
  - Lv.2→Lv.3: 150pt
  - ...

#### 消滅ボーナス
- Lv.8風船が2つ接触して消滅: 1000ポイント

#### コンボシステム
- 5秒以内に連続でマージが発生するとコンボ
- コンボ倍率: 1.5倍 → 2.0倍 → 2.5倍 → 3.0倍（上限）
- コンボが途切れるとリセット

### ゲームオーバー条件

- 画面上部の制限ライン（画面の90%位置）を風船が突破
- 突破状態が3秒間継続したらゲームオーバー
  - 一時的な突破は許容（風船が引っかかって戻る可能性）

### ゲームオーバー画面

表示内容:
- 最終スコア
- プレイ時間
- 最高コンボ数
- マージ回数
- リトライボタン
- ステージ選択に戻るボタン
